# AstroLearn user app

Open index.html in a browser. Keep the files in this folder together. The app can also be served by a static web host when testing on a phone. It does not require the AstroLearn testing service or an internet connection.

Explore shows approximate horizontal positions for a small bundled catalog of fixed objects. The starting site is Kuwait City and a blank time uses the device clock. The atlas and the target list use the same site and time. Search matches names and catalog IDs. Favorites and night mode are saved in the browser when local storage is available.

Observe pairs a chosen reference target with a local image preview. Images added in the current session can be reopened in the Images tab. A reload clears the session images. Telescope control and image identification are outside this prototype.

## Seestar comparison

| Seestar feature | AstroLearn user app |
| --- | --- |
| SkyAtlas target search and object categories | Local catalog search by name or identifier and a type filter |
| Best Tonight list and horizon view | Targets above the geometric horizon, sorted by altitude for the selected site and time |
| Favorites and GoTo | Favorites saved in the browser. Use in Observe opens a reference target alongside the image preview |
| Connected capture and album | Local image preview and session gallery |

References: [ZWO Seestar software](https://www.zwoastro.com/software/seestar/), [official Seestar app guide](https://www.seestar.com/blogs/seestar-guide/quick-guide-to-the-seestar-app) and [Seestar favorites guide](https://us.seestar.com/blogs/tutorial/how-to-add-custom-celestial-objects-in-seestar-app).

The bundled coordinates are drawn from AstroLearn's local catalogs. The reference image is the [NASA Moon Mosaic](https://science.nasa.gov/resource/moon-mosaic/), credited to NASA Scientific Visualization Studio / LRO.
