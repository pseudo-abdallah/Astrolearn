# Reference images

These are mission mosaics used for small recognition smoke tests, **not** a
representative ground-based telescope dataset or an accuracy benchmark.

- `moon.png`: [NASA Moon Mosaic](https://science.nasa.gov/resource/moon-mosaic/),
  NASA Scientific Visualization Studio / LRO. The page describes an LRO mosaic.
- `jupiter.jpg`: [Cassini Jupiter Portrait, PIA04866](https://science.nasa.gov/resource/cassini-jupiter-portrait/),
  credit NASA/JPL/Space Science Institute.

The app's local model returned **Possible Moon** and **Possible Jupiter** for
these reference images. Those tentative labels are not plate solutions.
The hosted image renditions were requested at 768×768; original source URLs and
credits above must remain with any redistributed examples.
